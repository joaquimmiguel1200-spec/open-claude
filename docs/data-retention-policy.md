# Política de Retenção de Dados — Open Claude

Dados são mantidos pelo período necessário à finalidade, segurança, suporte, obrigações legais ou defesa de direitos. Conteúdo de usuário deve ser excluído conforme mecanismos de conta e solicitações válidas, observadas retenções legais e registros de segurança.

Backups podem permanecer por período técnico limitado até sua rotação. Dados restaurados devem continuar sujeitos às mesmas proteções de acesso.
