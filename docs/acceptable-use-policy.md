# Política de Uso Aceitável — Open Claude

Última atualização: outubro de 2026

É permitido usar o Open Claude para tarefas lícitas de conversa, pesquisa, escrita, programação, organização, análise e automação dentro das permissões concedidas.

É proibido usar a plataforma para fraude, phishing, malware, invasão, exploração não autorizada, roubo ou exfiltração de credenciais, spam, abuso automatizado, evasão de controles, acesso a dados de terceiros, destruição deliberada de recursos ou violação de direitos.

Code, Cowork, GitHub e MCP só podem atuar sobre recursos para os quais o usuário possui autorização. Resultados de IA devem ser revisados antes de decisões de alto impacto ou alterações de produção.

Violações podem resultar em bloqueio de requisições, limitação, suspensão ou encerramento conforme os Termos, proporcionalidade, segurança e legislação aplicável. Contestações devem usar o canal oficial de suporte.
