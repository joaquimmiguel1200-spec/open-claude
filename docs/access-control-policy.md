# Política de Controle de Acesso — Open Claude

Acesso segue menor privilégio, necessidade de conhecimento e separação de funções. Usuários só acessam recursos autorizados; administradores usam contas protegidas por MFA e credenciais separadas.

RLS é a fronteira de autorização do banco quando aplicável. Tokens de serviço não devem ser expostos ao navegador. Permissões são revisadas periodicamente e revogadas quando deixam de ser necessárias.
