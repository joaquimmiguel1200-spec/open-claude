# Política de Incidentes — Open Claude

Incidentes são classificados por impacto, escopo, dados afetados e disponibilidade. A resposta segue: detecção → contenção → investigação → erradicação → recuperação → validação → comunicação → lições aprendidas.

Segredos comprometidos devem ser revogados/rotacionados. A equipe deve preservar evidências, limitar acesso aos envolvidos e evitar registrar dados pessoais ou credenciais desnecessárias. Incidentes envolvendo dados pessoais serão avaliados para comunicação às autoridades e titulares quando exigido pela legislação aplicável.
